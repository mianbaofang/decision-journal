# v0.10.1 - Review-round hardening + PyPI distribution

发布日期：2026-11-14

## 中文

v0.10.1 是 v0.10.0（身份统一）之后的第一个补丁版：把复审发现的问题一次修完，并补上 PyPI 发行。安装入口不变、命令不变、数据不迁移即可升级。

### 新增

- **PyPI 发行。** `pip install decision-journal` 即可装好 CLI 与 Web UI，命令为 `decision-journal`；README 与 README.en 的快速开始改为三条安装路径并列（skills CLI / PyPI / 源码），并加 PyPI 徽章。

### 修复

- **旧库迁移更安全。** 全新目标库走 SQLite backup API；已有数据的目标库用单次 `BEGIN IMMEDIATE` 合并：未 checkpoint 的 WAL 行不丢、绝不覆盖已有决策，`decisions` 按主键 `INSERT OR IGNORE`，`config` 只补缺失键。损坏的旧文件或没有 `decisions` 表的无关 SQLite 文件原样不动；并发启动串行化；迁移标记改名失败时可重试且保持幂等。
- **`--action stop` 只停自己的进程。** 仅处理命令行为本项目绝对路径 `backend/main.py` 的 loopback 后端；Windows 不再依赖 `-State Listen`（部分系统返回空）或子串匹配，POSIX 用 `lsof`/`ss` 解析监听 PID 并校验端口归属与绝对路径。远程或非 loopback 的 `--base-url` 绝不自动启动本地后端；没有停到进程时如实报告。
- **自动启动端口正确。** 本地自启把解析后的 host/port 传给 `backend/main.py`，非默认 `--base-url` 端口不再拉起多余的 8010 进程；`/api/health` 先核对后端 JSON 身份再认为端口就绪。
- **密钥不外泄。** 422 校验错误不再回显 API key；上游对话失败返回通用 502 而非透传 provider 消息；CLI HTTP 错误输出对已知 key 与 bearer token 做脱敏。
- **导出完整。** 决策简报导出的 Markdown 包含全部六个评分字段（含启发式 `评分信心`）。
- **安装包能直接用。** 安装包带上 `frontend/`，console script 可以直接起 Web UI；`__init__.py` 恢复跟踪（`/_*.py` 为根锚定），`scripts/sync_skill_package.py` 同步。
- **`--demo` 不再污染偏好。** `demoMode` 改为按请求设置、不写保存的偏好；CLI `--demo` 不会把之后的每次决策都变成 mock 数据，`demo/cli-demo.tape` 无真实 key 可跑。
- **测试更干净。** 测试不读真实用户 key、不默认连活后端；UI 套件跑在随机空闲端口的隔离临时库/配置上；需要真实后端的集成测试须显式设置 `DECISION_JOURNAL_TEST_BASE_URL`。
- **键盘可达性。** 最近决策列表改用原生 button，每条可 Tab 聚焦、Enter/Space 激活；首屏示例在六种语言下都本地化并在 1100px 以下隐藏；新增 `prefers-contrast: more` 块加强次级文字、线条与焦点环。
